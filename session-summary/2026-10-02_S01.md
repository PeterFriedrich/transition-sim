## 3. Technical Learnings
- **Playwright on the server lives in `/tmp/pw`**: `NODE_PATH=/tmp/pw/node_modules npm run verify`. An ESM scratch script cannot use `NODE_PATH`; use `createRequire('/tmp/pw/node_modules/')`.
- `tools/verify-sims.js` only shoots defaults. A scratch script that drives the controls is what found the real problems (the BEDMAS highlight gave away the next step; long sentences shrank to 8 px on a phone; the dissolved ions piled up; the crystal grew as a tangle until two-neighbour sites were made stickier).
- Float residue is real here: `−0.8 × 1.5` gave `−1.2000000000000002` until `bedmas.js` rounded each step. Decimals elsewhere are exact integers plus a place count.
- A whole `verify` run over 17 sims at two widths takes about a minute per theme; two themes plus `verify:built` exceed a 120 s command timeout.
- The catalog test fails until a new sim module is listed in `catalog.js`, which is the intended reminder.
